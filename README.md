# 스플린터 셀 트릴로지 한글패치 (PS3)

**Tom Clancy's Splinter Cell Trilogy** (PS3, **BLUS30761**, USA/Korea) 한글패치입니다.
1편 『스플린터 셀』, 2편 『판도라 투모로우』, 3편 『혼돈 이론』을 한글로 즐길 수 있습니다.

> 본 한글패치는 개인이 제작한 비공식·비상업적 팬 한글패치입니다. — by **Yonggary6425 (용가리)**
> 게임 파일(ISO)은 포함되어 있지 않습니다. 직접 소유한 원본으로만 사용해 주세요.

---

## 주요 특징

- **1·2·3편 영어 텍스트 한글화**: 메뉴, 임무 목표, 데이터·노트, 대화 자막, 로딩 화면
- **게임 중 음성 자막**: 원본에 자막이 없던 대사에도 한글 자막을 넣었습니다. 1편의 긴 통화 장면은 음성에 맞춰 나눠서 나옵니다.
- **컷신 동영상 자막 (선택)**: 오프닝을 포함한 동영상 52개에 한글 자막을 입힐 수 있습니다. 필요한 도구(ffmpeg)는 패처가 자동으로 받고, 끝나면 지웁니다.
- **ISO와 게임 폴더 모두 설치**: ISO는 원본을 두고 `원본이름_KOR.iso`를 새로 만들고, 폴더는 원본을 `.orig`로 보관합니다.
- **되돌리기 지원**: 폴더 설치는 버튼 하나로 원본으로 돌아갑니다.
- **RPCS3 설치 데이터 함께 패치**: 게임을 실행해 `dev_hdd0`에 설치된 데이터도 같이 바꿉니다.
- **RPCS3 버전 무관**: 실행 파일 자체를 패치하므로 RPCS3 게임 패치 기능의 변경에 영향을 받지 않습니다.
- 컬렉션 선택 화면과 각 편 타이틀 화면에 `LOCALIZATION BY YONGGARY` 표기

## 준비물

- **Tom Clancy's Splinter Cell Trilogy (USA, Korea)** / **BLUS30761** 원본 ISO 또는 게임 폴더
- Windows 10/11 (.NET Framework 4.x, 기본 설치되어 있음)
- RPCS3 (PC에서 플레이할 때)

## 다운로드

[Releases](../../releases)에서 최신 `SCT_KO_Patcher_v1.2.zip`을 받아 압축을 풉니다.
v1.2부터 패처는 `SCT_KO_Patcher.exe` **하나**입니다. 실행 파일 자체에 한글 처리 코드를 넣는 방식이라 RPCS3 버전에 영향을 받지 않습니다.


> [!IMPORTANT]
> **꼭 읽어 주세요 (PC/RPCS3 사용자)**
> RPCS3에서 이 게임을 **처음** 실행한다면, 아래 순서를 지켜야 추가 자막(1편 훈련 전 국장실 대화 등)이 나옵니다.
> 1. 패처로 설치합니다. (RPCS3 폴더 지정)
> 2. RPCS3에서 게임을 한 번 실행해 **타이틀 화면까지 간 뒤 종료**합니다.
> 3. 패처를 **한 번 더 실행**합니다. ISO 설치였다면 만들어진 `_KOR.iso`를 지정하면 빠르게 끝납니다.
>
> 이미 RPCS3에서 실행해 본 게임이면 RPCS3 폴더를 지정하고 한 번만 설치하면 됩니다.
> 게임이 처음 실행될 때 RPCS3에 복사하는 설치 데이터에는 한글패치가 새로 추가한 자막 파일이 들어가지 않기 때문입니다.

### 왜 실행 파일 패치 방식 하나로 바꿨나요?

v1.0·v1.1에는 패처가 두 가지 있었습니다.

| 방식 | 원리 | 장단점 |
|---|---|---|
| RPCS3 게임 패치 방식 (`SCT_KO_Patcher_RPCS3.exe`) | 실행 파일은 원본 그대로 두고, RPCS3가 게임을 켤 때 **RPCS3의 게임 패치 기능**으로 한글 처리 코드를 덧붙입니다. | 복호화가 필요 없어 간편했지만, 한글 표시가 RPCS3 기능에 달려 있습니다. |
| 실행 파일 패치 방식 (`SCT_KO_Patcher_ELF.exe`) | 한글 처리 코드를 **실행 파일 안에 직접** 넣습니다. | 처음 한 번 복호화가 필요하지만, RPCS3의 패치 기능을 쓰지 않습니다. |

그런데 v1.1 공개 후 RPCS3 게임 패치 방식에서 다음과 같은 제보가 이어졌습니다.

- **RPCS3 버전에 따라 한글이 깨졌습니다.** [Manage → Game Patches]에서 한글 패치를 켜 두어도, 메뉴와 자막이 깨진 글자로 나왔습니다. RPCS3의 게임 패치 처리 방식이 바뀐 것이 원인으로 보입니다.
- RPCS3는 거의 매일 새 빌드가 나오기 때문에, 이 방식은 앞으로도 RPCS3가 업데이트될 때마다 다시 깨질 수 있습니다.
- 패처가 두 개라 사용자가 어느 쪽을 써야 할지 헷갈려 하였습니다.

실행 파일 패치 방식은 한글 처리 코드가 실행 파일 자체에 들어 있어서 RPCS3 버전과 상관없이 똑같이 동작합니다. 최신 RPCS3 v0.0.43-20644에서도 정상으로 나오는 것을 확인했습니다.
복호화 과정이 조금 번거롭더라도 **어떤 RPCS3 버전에서나 확실하게 한글이 나오는 쪽**을 택해, v1.2부터 이 방식 하나로 통합했습니다.


## 적용 방법 (RPCS3)

### 1. 실행 파일 복호화 (처음 한 번)

PS3 실행 파일은 암호화되어 있어서, 갖고 있는 RPCS3로 먼저 복호화해야 합니다.

1. `SCT_KO_Patcher.exe`를 실행하고 **게임 폴더 / ISO**에 원본 ISO 또는 게임 폴더(`PS3_GAME`이 들어 있는 폴더)를 지정합니다.
2. **ISO**라면 **[ISO에서 실행 파일 꺼내기]** 버튼을 누릅니다. ISO 옆 `이름_SELF` 폴더에 `sc1/sc2/sc3.ppu.self`가 생깁니다.
   **게임 폴더**라면 `Data_SC\sc1.ppu.self`, `Data_SCPT\sc2.ppu.self`, `Data_SCCT\sc3.ppu.self`를 그대로 씁니다.
3. RPCS3 **Utilities → Decrypt PS3 Binaries**에서 위 `.self` 3개를 선택합니다. 같은 폴더에 `.elf`가 만들어집니다.

### 2. 설치

1. **RPCS3 폴더**에 `rpcs3.exe`가 있는 폴더를 지정합니다. (`rpcs3.exe` 파일이나 `dev_hdd0` 폴더를 골라도 찾아갑니다.)
2. 원하면 **동영상에 한글 자막 입히기**를 켭니다. (영상 하나에 수 초~1분)
3. **[설치]** 버튼을 누릅니다. 복호화한 `.elf`는 자동으로 찾습니다. 다른 곳에 두었다면 **복호화 ELF 폴더**로 지정하세요.
4. ISO 설치라면 RPCS3에서 만들어진 `원본이름_KOR.iso`를 실행합니다.
5. RPCS3에서 처음 실행하는 게임이었다면 위의 **꼭 읽어 주세요** 순서대로 패처를 한 번 더 실행합니다. 패처 화면 맨 위와 설치 끝 로그에도 같은 안내가 나옵니다.

### PS3 실기

- "PS3 실기"를 선택하면 패치된 ELF를 `SCT_KO_ELF` 폴더에 저장합니다.
- 이 ELF를 재서명 도구(TrueAncestor SELF Resigner, scetool 등)로 SELF로 만들어 게임의 `sc1/sc2/sc3.ppu.self`와 바꿔 주세요.
- PS3에 이미 설치된 게임 데이터(BLUS30761DATA)는 지운 뒤 실행하세요.
- **PS3 실기에서는 아직 테스트하지 못했습니다.**

## 주의

- 이 패치는 게임 **초기 버전(01.00)** 기준입니다. 01.01 업데이트를 설치하면 한글이 깨집니다. 업데이트가 설치되어 있다면 RPCS3의 `dev_hdd0\game\BLUS30761` 폴더를 다른 곳으로 옮겨(백업) 01.00으로 실행해 주세요.
- 항상 **원본**에 적용해 주세요. 이미 한글 패치된 `_KOR.iso`를 지정하면 ISO는 그대로 두고 RPCS3 설치 데이터만 처리합니다.
- v1.0·v1.1의 RPCS3 게임 패치(`patches\BLUS30761_patch.yml`)가 남아 있으면 v1.2 설치 때 함께 정리합니다.
- 테스트 환경: RPCS3 v0.0.43-20644, v0.0.42-19743

## 알려진 사항

- 1편의 일부 대사(CIA 분석관 테이프 장면, 대통령궁 일부)는 자막이 없습니다.
- 3편의 실시간 컷신 일부는 자막이 없습니다.
- 동영상 자막을 입히지 않으면 컷신 영상은 영어 음성만 나옵니다.
