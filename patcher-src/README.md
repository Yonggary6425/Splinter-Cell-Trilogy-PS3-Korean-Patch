# 스플린터 셀 트릴로지 (PS3, BLUS30761) 한글 패처

ISO 파일과 게임 폴더 모두에 설치할 수 있는 Windows용 한글 패처입니다.
게임 파일은 들어 있지 않고, **원본과 다른 부분(차이)과 한글 데이터만** 들어 있습니다.

## 1. 패처 만들기 (처음 한 번)

`build.bat`을 더블클릭하세요. 이 파일은 PowerShell 스크립트(`build.ps1`)를 실행합니다.

1. Windows에 들어 있는 C# 컴파일러(.NET Framework 4)로 패처를 컴파일합니다.
2. 경로 두 개를 묻습니다.
   - **한글화된 게임 폴더**: 지금까지 패치한 E: 드라이브 게임 폴더 (기본값)
   - **원본 ISO 또는 원본 폴더**: 있으면 지정하는 것을 권장합니다. 없으면 Enter를 누르세요. 이 경우 한글화 폴더의 `.orig` 백업과 비교합니다.
3. 두 폴더를 비교해 차이만 담은 패치 데이터를 만들고, 이 데이터를 넣어 패처 2종을 완성합니다.

| 파일 | 실행 파일 한글 패치 방법 (PC) |
|---|---|
| `build\SCT_KO_Patcher_ELF.exe` | **실행 파일 패치 방식**: RPCS3로 복호화한 .elf에 패치를 적용해 실행 파일(SELF)을 바꿉니다. |
| `build\SCT_KO_Patcher_RPCS3.exe` | **RPCS3 게임 패치 방식**: 실행 파일은 원본 그대로 두고, RPCS3 게임 패치(`patches\BLUS30761_patch.yml`)로 적용합니다. 복호화가 필요 없고, RPCS3 폴더 지정이 필수입니다. |

게임 데이터, ISO/폴더 설치, 동영상 자막, 되돌리기는 두 패처가 같습니다. PS3 실기는 두 패처 모두 복호화 → 재서명 방식입니다.

포함된 파일 목록은 `build\data.pack.txt`에서 확인할 수 있습니다.
동영상, 실행 파일(.self), 백업(.orig), DLSS용 부팅 파일(`_boot`), bat 파일은 비교 대상에서 빠집니다.

타이틀 화면의 크레딧 문구(`LOCALIZATION BY YONGGARY`)는 `credit\apply_credit.bat`으로 게임 폴더에 먼저 넣어 두면, 다른 한글화 파일과 마찬가지로 차이 데이터로 패처에 들어갑니다(컬렉션 선택 화면, 1·2·3편 타이틀 화면).

## 2. 설치

`SCT_KO_Patcher.exe`를 실행합니다.

| 항목 | 설명 |
|---|---|
| 게임 폴더 / ISO | 게임 폴더(PS3_GAME이 들어 있는 폴더)나 원본 ISO 파일 |
| PC (RPCS3) / PS3 실기 | 실행할 환경 |
| RPCS3 폴더 | 선택 항목. 지정하면 RPCS3에 이미 설치된 게임 데이터(`dev_hdd0\game\BLUS30761DATA`)도 함께 패치합니다. |
| 실행 파일(ELF) 패치 | 한글 표시에 필요하므로 켜 두세요. |
| 복호화 ELF 폴더 | 아래 "실행 파일 준비"를 참고하세요. |
| 동영상 자막 | 선택 항목. 아래 "동영상 자막"을 참고하세요. |

- **폴더 설치**: 파일을 그 자리에서 바꾸고, 원본은 `파일명.orig`로 보관합니다. 바꾼 목록은 `USRDIR\KO_PATCH_FILES.txt`에 기록합니다.
- **ISO 설치**: 원본 ISO는 그대로 두고, 같은 폴더에 `원본이름_KOR.iso`를 새로 만듭니다. 원본 크기만큼의 여유 공간이 필요합니다.

### RPCS3 게임 패치 방식 (`SCT_KO_Patcher_RPCS3.exe`)

- RPCS3 폴더를 지정하고 설치하면 `patches\BLUS30761_patch.yml`을 만들고 `config\patch_config.yml`에서 자동으로 켭니다.
- RPCS3 [Manage → Game Patches]에서 "Korean patch (SC1/SC2/SC3)"가 켜져 있는지 확인할 수 있습니다.
- 실행 파일 패치 방식으로 바꿔 둔 폴더에 설치하면, 실행 파일을 `.orig` 원본으로 되돌린 뒤 게임 패치를 씁니다. 게임 패치는 원본 실행 파일에만 적용되기 때문입니다.

### 실행 파일 준비 (실행 파일 패치 방식, PS3 실기)

PS3 실행 파일은 암호화되어 있어서, 사용자의 RPCS3로 먼저 복호화해야 합니다.

1. **ISO 설치**: ISO를 지정하고 **[ISO에서 실행 파일 꺼내기]**를 누르세요. ISO 옆에 `이름_SELF` 폴더가 생기고 `sc1/sc2/sc3.ppu.self`가 들어갑니다.
   **폴더 설치**: 게임 폴더의 `Data_SC\sc1.ppu.self`, `Data_SCPT\sc2.ppu.self`, `Data_SCCT\sc3.ppu.self`를 그대로 사용합니다.
2. RPCS3 메뉴 **Utilities → Decrypt PS3 Binaries**에서 위의 `.self` 3개를 선택합니다. 같은 폴더에 `.elf`가 만들어집니다.
3. **ISO 설치**: `이름_SELF` 폴더는 자동으로 찾습니다. 다른 곳에 두었다면 "복호화 ELF 폴더"로 지정하세요.
   **폴더 설치**: 게임 폴더 안의 `.elf`를 자동으로 찾습니다.

패처는 SHA-256으로 원본 ELF인지 확인한 뒤 한글 패치를 적용하고, RPCS3용 SELF를 만들어 넣습니다.

### PS3 실기

- "PS3 실기"를 선택하면 실행 파일을 바꾸지 않습니다. 대신 패치된 ELF를 게임 폴더(또는 ISO) 옆의 `SCT_KO_ELF` 폴더에 저장합니다.
- 이 ELF를 TrueAncestor SELF Resigner나 scetool 같은 재서명 도구로 SELF로 만든 뒤, 게임의 `sc1/sc2/sc3.ppu.self`와 바꿔 주세요.
- 재서명한 SELF를 넣기 쉬우므로 PS3 실기는 **폴더 설치**를 권장합니다.
- PS3에 이미 설치된 게임 데이터(설정 → 게임 데이터 유틸리티의 BLUS30761DATA)는 지운 뒤 실행하세요.

## 3. 동영상 자막 (선택)

"동영상에 한글 자막 입히기"를 켜면 오프닝을 포함한 동영상 55개에 한글 자막을 입힙니다. 1편, 2편, 3편 중 원하는 것만 고를 수 있습니다.

- 필요한 도구는 공식 사이트에서 임시 폴더로 자동으로 받습니다.
  - ffmpeg (gyan.dev, SHA-256 확인)
  - RAD Video Tools (radgametools.com, 디지털 서명 확인)
- 작업이 끝나면 도구와 임시 파일을 모두 지웁니다. 이미 설치된 도구가 있으면 경로를 지정해 그것을 써도 됩니다.
- 원본 오디오 트랙 5개(언어별)는 그대로 유지하고, 영상만 다시 인코딩합니다.
- 시간이 오래 걸립니다(PC에 따라 1~2시간). 영상 하나를 처리할 때 임시 폴더 드라이브에 수 GB의 여유 공간이 필요합니다.
- 원본이 아닌 영상(이미 자막이 들어간 영상 등)은 건너뜁니다.

## 4. 되돌리기

- **폴더 설치**: [되돌리기]를 누르면 `.orig` 백업으로 복원하고, 새로 추가한 파일은 지웁니다. RPCS3 폴더를 지정했다면 RPCS3 설치 데이터도 함께 되돌립니다.
- **ISO 설치**: 만들어진 `_KOR.iso`를 지우면 됩니다.

## 명령줄 사용

```
SCT_KO_Patcher.exe --game <폴더|ISO> [--rpcs3 <폴더>] [--elf-dir <폴더>] [--no-exe] [--ps3]
                   [--video 123] [--ffmpeg <exe>] [--rad <exe>] [--log <파일>]
SCT_KO_Patcher.exe --game <ISO> --extract-self
SCT_KO_Patcher.exe --game <폴더> --rpcs3 <폴더> --uninstall
SCT_KO_Patcher.exe --make-pack --patched <한글화 폴더> [--orig <원본 ISO|폴더>] --out <파일>
```

`--video`에서 경로를 생략한 도구는 자동으로 받습니다. 이 경우 RAD Video Tools 사용권에 동의한 것으로 봅니다.
